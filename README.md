# doz — плата дозатора

Проект платы в KiCad 10.

- `doz.kicad_pro`, `doz.kicad_sch`, `doz.kicad_pcb` — исходники проекта.
- `doz-B_Cu.pdf` — чертёж нижнего слоя для печати.
- `bom/ibom.html` — интерактивная ведомость деталей.
- `doz.ses`, `doz.rules` — результат и правила Freerouting.

Для правки знаков и посадочных мест нужны библиотеки `TrueLib` и `PCM_SparkFun`, подключённые в KiCad. Плата и схема хранят свои копии используемых элементов и открываются без этих библиотек.

Перед изготовлением проверьте правила платы в KiCad и печатайте PDF с масштабом 100 %.
